Quiero que generes un sistema web completo de Biblioteca Virtual usando arquitectura MVC profesional con PHP orientado a objetos, MySQL, HTML5, CSS3, Bootstrap 5 y JavaScript.

El sistema NO será de préstamos físicos. Será exclusivamente una plataforma de consulta y lectura de libros virtuales (PDFs).

# OBJETIVO

Crear una biblioteca virtual académica moderna donde:

- Administradores gestionen usuarios y libros
- Docentes y estudiantes consulten libros digitales
- Los libros puedan visualizarse online
- Existan roles y permisos
- El sistema tenga dashboards separados según el rol
